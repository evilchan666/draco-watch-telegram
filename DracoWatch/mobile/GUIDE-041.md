# Watch 0.4.1 — Environment on a phone

- **Overview** fits all six stations. Drag the scene to orbit; pinch to zoom.
- **Camera → Focus agent** gives the selected creature a closer view. Overview
  returns to the whole room. Camera tools close after either action.
- Select a creature or its named button to inspect it without leaving the room.
  The selected identity and observed phase stay in the dock. An open run is not
  automatically labelled productive work; unavailable execution stays unknown.
- **Read** opens the full selected observation in a scrollable reading surface.
  Close returns to the same camera and selected agent. A replacement session
  closes the old reader rather than silently showing it under a different owner.
- **Conversation & pins** opens that agent's chat; **Work details** opens Activity.
  Short landscape uses the labels **Chat & pins** and **Work** for these same
  actions. All six named agent destinations remain available.
- In short landscape only the selected name is repeated in the scene, avoiding
  overlapping labels. The named destinations below/beside it remain intact.
- **Camera → Report preview** is still the saved master switch. Idle previews
  expire after sixty seconds; reading does not revive them. Chat and pin history
  are retained. Audio remains manual and bound to the chosen report.

Install available updates through **Settings → Check updates → Install**.
For a reproducible layout or interaction fault, **Settings → Watch debugger**
retains version, viewport, scene and error diagnostics for inspection/export.

Android emulator and browser checks are not proof of physical S25 smoothness or
operator acceptance. The previous 0.4.0 package remains a preserved recovery
artifact; it is not automatically reinstalled.
