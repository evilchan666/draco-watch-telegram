# DRACO Watch 0.7 — conversation is part of the workspace

The first-person environment remains present when you communicate. **Talk**
opens the complete existing native conversation in a bottom panel in portrait,
or alongside the world in landscape. This is not a preview message or a new
transport. It uses the existing authenticated history, composer and outbox.

## Use the workspace

- Select an agent in the contact strip, or look at an agent and choose **Talk**.
  The panel names the recipient and shows only its selected session.
- Read, type and send without switching away from the world. Movement pauses
  while the conversation is open; typing never turns into walking.
- Use Attach or the microphone. Recording finishes into the same agent's draft;
  it does not send automatically. Switching agents during recording is refused.
- Tap the staged-files/outbox banner, or choose **Files, drafts and outbox**
  from the conversation menu. Review the unsent draft, preview/remove files,
  clear a reply reference or inspect the original unconfirmed request in native
  dialogs. Opening review never switches to a second composer.
- An unconfirmed submission keeps its original ID. **Check original ID** appears
  only when retry is supported. Steer is never silently replaced by Queue or
  replayed. Files belonging to unresolved submissions cannot be removed.
- Use the expand icon for more reading room. Collapse restores the panel;
  Back closes the conversation and returns to the same position and look.
- **Explore** explicitly restores movement. Agent switching preserves separate
  unsent drafts. Selecting the current agent preserves reply/search context.

Pins, message actions, available media, public work evidence, commands, history
and supported exact-run controls remain accessible. Stop is labelled unavailable
when there is no supported exact target. Advanced HTML controls and complete
formatted reports remain available as labelled fallbacks within the workspace.
Settings, diagnostics and original-record dialogs may temporarily cover it.

## Connection trouble

**DRACO → Connection settings → Connection & diagnostics** works without a
gateway connection. Check connection reads the current snapshot. It does not
send drafts, reset pairing, replay input or release a continuation hold.

## Verification boundary

The local Android fixture exercises the real native panel, Android keyboard,
enlarged text, orientation changes and all six recipients. Admissions, history,
file and recorder results in that fixture are synthetic; no live agent is sent
test input. This is not physical-phone acceptance or proof that the previously
reported S25 connection failure is resolved. The room geometry is unchanged.
The native integration remains a Telegram-derived component subset, not full
upstream Telegram chat-stack parity or a Telegram login migration.
