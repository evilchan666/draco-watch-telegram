# DRACO Watch 0.8 — operating space

The world remains the starting screen. Drag the scene to look and use the left
movement pad to walk. Tap an agent or their physical workstation to select them.
**Talk to …** names the recipient before opening a conversation.

There is one world toolbar and one conversation sheet. The old mode tabs,
floating report card and separate Operations dashboard entry are no longer in
the main flow. The diamond menu contains space settings and secondary tools;
it is not a second agent chooser.

## Conversations without leaving the world

- **Agents · 6** opens six fixed contact slots. Choosing one opens that agent's
  existing native conversation, with its own draft, replies and staged files.
- The conversation is the same native timeline and composer as its expanded
  view. Drag the grip upward to expand, downward to dock, or use the accessible
  expand button. Scrolling messages does not drag the sheet.
- Type, attach files, record deliberately, select send mode, review the outbox,
  reply or pin using the existing controls. Unavailable actions do not dispatch.
- Tap the conversation title for work, state and history coverage. Its overflow
  menu contains pins, outbox and other conversation tools, all bound to that
  recipient. Work records remain in the native timeline.
- The conversation Back arrow or Android Back closes only the conversation. Position and view are
  retained. Movement pauses while reading, choosing a recipient or typing.

## Know which build is actually running

Tap the connection pill. **Running on this device** comes from Android
package metadata. A downloaded update is explicitly **not installed** until
Android completes installation; the app never promotes a download into an
installed-version claim. Check updates and finish Android's installation prompt
there. Cancelling installation leaves the previous app unchanged.

The same panel separates the native bridge, gateway observation and selected
session. **Device diagnostics** opens the local connection details even when the
gateway is unreachable. Checking the connection never replays an uncertain send,
clears drafts or resets pairing.

## Evidence boundary

Preview screenshots use an unpaired emulator and synthetic messages. They are
not live fleet work or evidence of installation, connectivity or frame rate on a
physical S25. Existing pairing, distinct identities, approved voices and the
previous signed release are retained. Full Telegram feature parity is not claimed.
