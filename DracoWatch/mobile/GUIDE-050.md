# DRACO Watch 0.5.0 — inside the operating space

Environment is now the starting screen and uses the full display. You have a local
first-person position instead of orbiting a miniature room.

- Drag the left movement pad to walk/strafe. Drag the room separately to look.
  WASD/arrows work with a keyboard. Solid consoles and walls stop movement.
- Look at an agent and tap **Talk**, or tap the agent first. **Agents & tools**
  names its current target and lets you select any of the six agents.
- Talk opens that agent's full existing conversation: drafts, files/recording,
  pins/history, replies/commands, manual approved audio and supported run controls.
  The extra composer retains attachment review and uncertain-request custody.
- Back closes the current dialog, returns from the extra composer to native chat,
  and then returns you to your exact place in the world. Conversation does not
  keep the movement pad held down.
- **DRACO → Settings / Activity / Chamber** opens the existing surfaces. Back
  returns to Environment. **Reset my position** returns to the initial spawn.
- Android bars hide only in the world. Swipe from an edge to reveal them;
  conversation, menus, Settings and the keyboard restore normal system controls.
- The connection button reports **gateway feed** freshness, not proof that a new
  message or control was accepted. Reconnect and native pairing settings are in
  the menu. **Settings → Watch debugger → Export** retains bounded snapshot
  failure classes/status/timing without including connection credentials.

Pairing and prior releases are preserved. No silent installation, live-control
acceptance, physical S25 smoothness, complete Telegram parity or networked local
avatar is claimed. Agent artwork is preserved; it is not a new volumetric rig.
