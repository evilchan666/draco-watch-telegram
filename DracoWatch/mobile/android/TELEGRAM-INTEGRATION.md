## Evidence policy

Browser checks exercise the structured bridge and exact session/run races using
fake native transport, never production input. Native checks instantiate actual
components, actions and revision expansion on an unpaired emulator. A separate
bridge check exercises actual bundled JavaScript → native render and native
composer → JavaScript state. Failed initial launch/harness runs are retained
separately from passing evidence. Synthetic callbacks do not establish live
Stop, genuine reply, physical audibility or sustained device reliability.

Clickable memory citations remain unavailable without an audience-bound original
source/revision resolver. Conditional host nested-event support is not invented
from wrapper prose. Existing missing upstream fields and delivery-leg acceptance
remain explicit; no claim that pinning or native presentation supplies them.
